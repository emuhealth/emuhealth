Local drop-in replacement for Vercel, GitHub, Google, Slack, Apple, Microsoft, Okta, AWS, Resend, Stripe, MongoDB Atlas, Clerk, Linear, and Twilio APIs. Built for CI and no-network sandboxes. Fully stateful, production-fidelity API emulation. Not mocks.

> **Synthetic data only.** emuhealth is a development and testing tool. Never load real patient data or other protected health information (PHI) into it. Emulators keep data in memory or local files with no access controls, audit logging, or encryption.

## Quick Start

```bash
npx emuhealth
```

## CLI

```bash
# Start all services (zero-config)
npx emuhealth

# Start specific services
npx emuhealth --service vercel,github

# Custom port
npx emuhealth --port 3000

# Use a seed config file
npx emuhealth --seed config.yaml

# Generate omitted service secrets into a private file
npx emuhealth start --seed config.yaml --generated-secrets-file .emulate-secrets.json

# Generate a starter config
npx emuhealth init

# Generate config for a specific service
npx emuhealth init --service github

# List available services
npx emuhealth list
```

The generated-secrets destination must not exist. emuhealth removes inherited ACLs, verifies effective owner-only access, and publishes the complete file before startup. Handled startup failures remove the invocation-owned artifact. A hard termination can leave a complete artifact that requires manual recovery. Linux requires `setfacl` and `getfacl` from the `acl` package. The flag fails closed when access controls cannot be verified and is not supported on Windows.

The port can also be set via the `EMUHEALTH_PORT` or `PORT` environment variables. The upstream name `EMULATE_PORT` still works when `EMUHEALTH_PORT` is not set.

For access from a container or another machine, use `npx emuhealth start --host 0.0.0.0`. Set `--base-url` to a URL reachable by those clients when using OAuth redirects or other advertised URLs.

## Programmatic API

You can also use emuhealth as a library in your tests. See the [Programmatic API](/docs/programmatic-api) page for `createEmulator`, Vitest/Jest setup, and instance methods.

## Framework Integration

Embed emulators directly in your Next.js or Nuxt app so they run on the same origin. See the [Next.js Integration](/docs/nextjs) and [Nuxt Integration](/docs/nuxt) pages for setup instructions.

GitHub App flows expose secret-free installation-token metadata through an emulator-only inspection route. See the [GitHub documentation](/docs/github) for details.
