# Decision Records

Short records of decisions that shape emuhealth. Each file captures the context, the decision, and its consequences so contributors and agents understand why things are the way they are.

Rules:

- Number files sequentially: `NNNN-short-title.md`.
- Records are append-only. To change a decision, add a new record and set the old one's status to `Superseded by NNNN`.
- Keep each record short. Link to [ROADMAP.md](../../ROADMAP.md) items it affects.
